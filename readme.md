# 🧹 Website Piket Kelas

Aplikasi web modern, ringan, dan responsif untuk mengelola serta memantau jadwal piket harian kelas. Dilengkapi dengan fitur ekspor gambar agar mudah dibagikan langsung ke grup WhatsApp/Telegram kelas.

---

## 🌟 Fitur Utama

- **Tampilan Kalender Interaktif**: Melihat jadwal piket bulanan secara ringkas.
- **Status Piket Berwarna**:
  - 🟢 **Piket**: Hadir dan menjalankan tugas piket.
  - 🟡 **Tidak piket**: Berhalangan / izin / sakit.
  - 🔴 **Kabur**: Tidak menjalankan piket tanpa keterangan.
- **📸 Fitur Tangkap Layar (Export PNG)**: Ekspor tampilan kalender bulanan menjadi gambar resolusi tinggi untuk dibagikan ke grup kelas.
- **⚙️ Panel Admin Terproteksi**: Atur dan ubah status piket harian serta tambah data siswa baru dengan kata sandi admin.
- **Mobile Friendly**: Tampilan optimal untuk diakses dari smartphone maupun laptop.

---

## 🛠️ Teknologi yang Digunakan

- **Frontend**: HTML5, CSS3 (*Custom Flexbox & Grid*), Vanilla JavaScript.
- **Fonts**: [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans) via Google Fonts.
- **Library**: `html2canvas` (untuk fitur konversi tampilan ke gambar PNG).
- **Database (Opsional)**: PostgreSQL / Supabase.
